Change time and images used by editing the final number in .cursor files inside `Horse-Cursors-Files`. For example:

```
32 1 9 Horse-Busy1.png 35
32 1 9 Horse-Busy2.png 35
[...]
```
The number at the end, '35', is the time in **milliseconds** that will take to change from a image to the next. If you want it faster, decrease it, or increase it for faster animations.
